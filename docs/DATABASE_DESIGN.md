# VerifyNow Database Design
Version: 0.1.0

---

# Purpose

This document defines the production database architecture for VerifyNow.

Every database table, relationship, enum and index must be documented here before implementation.

Prisma Schema and Supabase PostgreSQL must always remain synchronized with this document.

---

# Design Principles

- Multi-tenant
- API First
- Provider Agnostic
- Audit Everything
- Security by Default
- Scalable
- Normalized
- Soft Delete where appropriate

Cascade deletion of dependent temporary records only.

Audit records are never deleted.
